# 在线学习平台人工功能测试表格版

> 用途：给测试负责人分配人员、记录执行结果、判断项目功能是否正常。
>
> 执行方式：以浏览器手工测试为主，必要时使用 `http://localhost:8000/docs` 做接口补测。
>
> 填写建议：测试人员复制本文档表格到在线表格后，可补充“负责人、执行结果、问题编号、复测结果”。

## 1. 测试环境表

| 项目 | 内容 | 备注 |
|---|---|---|

| 后端地址 | `http://localhost:8000` | FastAPI 服务 |
| 接口文档 | `http://localhost:8000/docs` | Swagger，可用于接口补测 |
| 推荐浏览器 | Chrome / Edge 最新版 | 建议使用无痕窗口切换角色 |
