# 在线学习平台人工功能测试计划

> 适用版本：当前工作区已挂载的前端路由与后端接口版本。
>
> 测试目标：让测试人员按清单逐项确认平台“正常不正常”，重点验证主流程、角色权限、文件上传和关键页面闭环。
>
> 测试方式：以浏览器手工测试为主，必要时结合 `http://localhost:8000/docs` 做接口补测。

## 1. 文档目的

1. 验证在线学习平台在日常使用场景下是否能正常工作。
2. 统一测试范围、角色账号、执行顺序和预期结果，减少漏测和重复沟通。
3. 让非开发测试人员可以直接按本文件执行，不需要理解具体实现代码。
4. 本文档只关注功能正确性与基本可用性，不覆盖性能压测、兼容性专项和安全渗透测试。

## 2. 测试范围与角色说明

| 角色 | 主要验证范围 | 备注 |
|---|---|---|
| 学员（student） | 首页浏览、课程详情、学习页与进度、个人中心、消息、反馈、头像上传 | 以 `student1` 为主，`student2` 用于对照测试 |
| 讲师（teacher） | 教师课程管理、课程内容编辑、资源/资料上传、讲师反馈处理 | 以 `teacher1` 为主，`teacher2` 用于越权对照 |
| 管理员（admin） | 用户管理、讲师审核、分类/标签/公告、系统消息、反馈管理 | 以 `admin1` 为主 |
| 未登录用户 | 首页、课程浏览、课程详情、公开分类/标签/公告 | 主要验证公开页面与路由守卫 |

### 角色口径

- 登录方式统一使用页面登录，必要时可在 `http://localhost:8000/docs` 里核对接口。
- 前后端统一口径为：`/api/v1`、Bearer Token、`student / teacher / admin`、`{ code, message, data }`。
- 访问教师后台、管理员后台、学习页等受限页面时，既要看页面是否跳转，也要看接口返回是否符合权限预期。
- 若页面暂未提供某个按钮，但后端接口已存在，可通过 Swagger 补测，并在备注里标明“API补测”。

## 6. 异常与边界补充项

以下内容不一定都放在主流程里，但建议至少抽测：

- 登录失败：密码错误、账号不存在、连续多次错误登录。
- 账号状态：禁用账号、未激活账号、切换角色后旧登录态残留。
- 权限越界：学员访问教师/管理员页面，教师访问管理员页面，普通用户直接调用管理接口。
- 课程状态：未发布课程不能被学员正常学习，已下架课程不应继续作为学习入口。
- 表单边界：必填项为空、超长标题、特殊字符、重复提交。
- 反馈边界：内容为空、图片过多、图片过大、目标老师未选。
- 上传边界：文件类型不符、文件过大、空文件、上传中断、分片顺序错误。
- 消息边界：空列表、最后一页、全部已读后再次执行、删除后刷新。
- 分页边界：第一页、最后一页、超大页码、页大小切换。
- 页面边界：浏览器刷新后状态是否仍一致，页面返回后是否恢复数据。
- 口径边界：页面拦截通过，但接口仍可访问，或页面放行但接口返回 403；都要记录为前后端口径问题。

## 7. 验收标准

满足以下条件即可认为本轮人工功能测试通过：

1. 所有 P0 用例通过。
2. P1 用例无阻断性问题，若有问题必须有明确解决方案和复测结论。
3. 三类主角色闭环可用：
   - 学员：浏览课程 → 进入学习页 → 保存进度 → 查看个人中心/消息/反馈。
   - 讲师：创建或编辑课程 → 上传内容与资源 → 处理课程反馈。
   - 管理员：管理用户 → 审核讲师 → 维护分类/标签/公告 → 发送系统消息。
4. 公开页面、登录页、教师页、管理员页都能正确路由，不出现白屏或死循环跳转。
5. 文件上传链路可用，上传后的 URL 能正常访问。
6. 关键字段显示正确，没有明显的角色串号、数据串号或权限串号。
7. 发现的问题都已登记并完成复测，测试结论明确。

## 8. 常见问题与处理建议

| 现象 | 常见原因 | 处理建议 |
|---|---|---|
| 提示未授权 / 401 | 没登录、Token 过期、浏览器存了旧登录态 | 重新登录，必要时清理 localStorage 后再试 |
| 提示无权限 / 403 | 角色不匹配、权限码不足、越权访问 | 换对应角色账号，或记录为权限缺陷 |
| 页面白屏或一直转圈 | 路由异常、接口返回异常、前端缓存未刷新 | 先刷新页面，再清缓存或无痕模式重试 |
| 422 参数错误 | 字段缺失、格式不对、上传表单不符合要求 | 对照用例重新填写，检查必填字段 |
| 上传失败 | 文件类型不支持、文件过大、账号权限不对 | 换测试文件、换角色或检查接口说明 |
| 消息 / 反馈不更新 | 页面未刷新、接口有延迟、账号切换后未重新登录 | 刷新页面并重新登录后复测 |
| 课程详情能看，学习页不能进 | 课程未发布、资源未绑定或学习状态异常 | 先确认课程状态，再检查资源链路 |
| 管理后台页面打不开 | 不是管理员账号、管理员权限未加载 | 使用 `admin1` 重登后复测 |
| 看见的数据不是当前账号的 | 账号切换后缓存未清理 | 退出并清理浏览器缓存后重测 |

## 9. 备注
