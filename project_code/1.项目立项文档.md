 # 项目立项文档

## 一、项目目标

## 1.提供一个在线学习的视频网站。

## 二、项目背景

## 1.自己搭建一个在线学习视频网站，然后把自己有的学习资源作为一个赠品送出去。（多拥有一部分竞争力）

## 三、 目标用户

## 1. 学校（学生，老师，管理员）。

## 四、 核心问题

## 1. 本项目为视频相关开发项目，目标是完成一套可本地运行的  视频播放，PPT展示系统 ，实现核心功能可用、界面基础可用。

## 五、核心功能：

​	基础视频上传 / 播放 / 预览

​	核心业务逻辑（任务逐步完成）

​	本地运行、基础界面

​	基础数据存储

## 六、非目标功能

1.不做积分，支付，课程购买

2.不做课堂答题，签到等

3.不做营销，预约等

4.不做复杂权限、会员、付费系统

5.不做第三方平台对接（如抖音 / B 站 API）

6.不做云端部署、服务器上线

## 七、预期上线时间

本周星期五

## 八、交付边界

1.完成核心功能，视频上传功能，任务划分功能等基础功能

2.正常启动、运行、演示

3.不追求完美优化，满足普通学员正常使用，不进行过度优化与迭代
