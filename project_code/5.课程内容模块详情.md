## 模块概述

课程内容模块负责管理课程的章节、小节和学习资源。章节是课程的顶级组织单元，小节属于章节，学习资源属于小节。本模块包含10个接口，实现课程内容的增删改查操作。

---

## 数据层级关系

```
课程 (Course)
└── 章节 (Chapter)
    └── 小节 (Section)
        └── 学习资源 (Resource)
            ├── 视频 (video)
            ├── 音频 (audio)
            ├── 文档 (document)
            └── 图片 (image)
```

## 一、创建章节

### 1. 基本信息

| 项目 | 内容 |
|------|------|
| 接口名称 | 创建章节 |
| 接口路径 | /api/v1/courses/{course_id}/chapters |
| HTTP方法 | POST |
| 功能描述 | 为课程创建新的章节，章节按创建顺序或指定序号排列 |

### 2. 请求参数

#### Path参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| course_id | integer | 是 | 课程ID |

#### 请求体JSON

```json
{
  "title": "第一章 Python基础",
  "sort_order": 1
}
```

#### 参数说明

| 参数 | 类型 | 必填 | 说明 | 验证规则 |
|------|------|------|------|----------|
| title | string | 是 | 章节标题 | 2-50字符，不能包含特殊字符 |
| sort_order | integer | 否 | 排序序号 | 非负整数，默认按创建顺序 |

### 3. 响应结构

#### 成功响应

```json
{
  "code": 200,
  "message": "章节创建成功",
  "data": {
    "chapter_id": 1,
    "title": "第一章 Python基础",
    "sort_order": 1,
    "created_at": "2026-03-17T10:00:00"
  }
}
```

#### 失败响应

| 场景 | code | message |
|------|------|---------|
| 权限不足 | 403 | 权限不足 |
| 课程不存在 | 404 | 课程不存在 |
| 非课程创建者 | 403 | 无权限操作此课程 |
| 标题格式错误 | 422 | 章节标题长度需在2-50字符之间 |

### 4. 业务逻辑

```
开始
  ↓
验证讲师或管理员权限
  ├── 否 → 返回403错误
  └── 是 → 继续
  ↓
验证课程存在性
  ├── 不存在 → 返回404错误
  └── 存在 → 继续
  ↓
检查是否为课程创建者
  ├── 否 → 返回403错误
  └── 是 → 继续
  ↓
验证标题格式
  ├── 不符合 → 返回422错误
  └── 符合 → 继续
  ↓
计算排序序号
  ├── 指定了sort_order → 使用指定值
  └── 未指定 → 使用当前章节数+1
  ↓
创建章节记录
  ↓
更新课程修改时间
  ↓
返回章节信息
结束
```

### 5. 数据库操作

- **涉及数据表**：chapters, courses
- **操作类型**：插入、更新

```python
# SQLAlchemy示例
async with db.begin():
    # 获取当前章节数量用于计算默认序号
    count = await db.scalar(
        select(func.count()).where(Chapter.course_id == course_id)
    )

    # 创建章节
    chapter = Chapter(
        course_id=course_id,
        title=request.title,
        sort_order=request.sort_order or (count + 1)
    )
    db.add(chapter)
    await db.flush()

    # 更新课程修改时间
    await db.execute(
        update(Course)
        .where(Course.id == course_id)
        .values(updated_at=datetime.now())
    )
```

#### Pydantic模型

```python
# schemas/content.py
from pydantic import BaseModel, Field, field_validator
import re

class ChapterCreateRequest(BaseModel):
    title: str = Field(..., min_length=2, max_length=50)
    sort_order: Optional[int] = Field(None, ge=0)

    @field_validator('title')
    @classmethod
    def validate_title(cls, v):
        # 过滤特殊字符
        if re.search(r'[<>&"\'/]', v):
            raise ValueError('标题不能包含特殊字符')
        return v.strip()

class ChapterResponse(BaseModel):
    chapter_id: int
    title: str
    sort_order: int
    created_at: datetime
```

#### 路由函数

```python
# api/v1/content.py
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession

router = APIRouter(tags=["课程内容"])

@router.post("/courses/{course_id}/chapters", response_model=ApiResponse[ChapterResponse])
async def create_chapter(
    course_id: int,
    request: ChapterCreateRequest,
    current_user: User = Depends(require_teacher_or_admin),
    db: AsyncSession = Depends(get_db)
):
    # 检查课程权限
    course = await course_service.get_course_by_id(db, course_id)
    if not course:
        raise HTTPException(status_code=404, detail="课程不存在")
    if course.teacher_id != current_user.id and current_user.role != 'admin':
        raise HTTPException(status_code=403, detail="无权限操作此课程")

    chapter = await content_service.create_chapter(db, course_id, request)
    return ApiResponse(message="章节创建成功", data=chapter)
```

### 4. 业务逻辑

```
开始
  ↓
验证权限
  ↓
查询章节是否存在
  ├── 不存在 → 返回404错误
  └── 存在 → 继续
  ↓
检查课程所有权
  ├── 非创建者 → 返回403错误
  └── 创建者 → 继续
```

```
  ├── 已发布 → 返回400错误
  └── 草稿/已下架 → 继续
  ↓
开启数据库事务
  ↓
删除章节下所有资源
  ↓
删除章节下所有小节
  ↓
删除章节
  ↓
重新计算其他章节的排序序号
  ↓
提交事务
  ↓
删除存储的文件资源
  ↓
返回成功
结束
```

### 5. 数据库操作

- **涉及数据表**：chapters, sections, resources
- **操作类型**：删除

```python
# SQLAlchemy示例
async with db.begin():
    # 获取要删除的资源文件URL
    resource_urls = await db.execute(
        select(Resource.file_url)
        .join(Section)
        .where(Section.chapter_id == chapter_id)
    )

    # 删除资源
    await db.execute(
        delete(Resource)
        .where(Resource.section_id.in_(
            select(Section.id).where(Section.chapter_id == chapter_id)
        ))
    )

    # 删除小节
    await db.execute(
        delete(Section).where(Section.chapter_id == chapter_id)
    )

    # 删除章节
    await db.execute(
        delete(Chapter).where(Chapter.id == chapter_id)
    )

    # 重新计算排序
    await db.execute(
        text("""
            UPDATE chapters
            SET sort_order = sort_order - 1
            WHERE course_id = :course_id
            AND sort_order > :deleted_order
        """),
        {"course_id": course_id, "deleted_order": deleted_order}
    )
```

### 9. 代码组织建议

```python
# services/content_service.py
async def delete_chapter(
    self,
    db: AsyncSession,
    course_id: int,
    chapter_id: int,
    teacher_id: int
) -> None:
    """删除章节及其关联数据"""
    # 检查权限
    course = await self.check_course_owner(db, course_id, teacher_id)

    if course.status == 'published':
        raise ValueError("已发布课程无法删除章节，请先下架")

    # 获取章节信息
    chapter = await self.get_chapter_by_id(db, chapter_id)
    if not chapter or chapter.course_id != course_id:
        raise ValueError("章节不存在")

    # 获取要删除的文件
    files_to_delete = await self.get_chapter_files(db, chapter_id)

    # 删除数据库记录
    async with db.begin():
        await self._delete_chapter_data(db, chapter_id, chapter.sort_order)

    # 异步删除文件
    await file_service.delete_files_async(files_to_delete)
```

```sql
    c.id as chapter_id,
    c.title,
    c.sort_order,

GROUP BY c.id
ORDER BY c.sort_order;
```

```python
# services/resource_service.py
import os
from pathlib import Path
from typing import Tuple

class ResourceService:
    # 文件类型配置
    ALLOWED_EXTENSIONS = {
        'video': {'.mp4'},
        'audio': {'.mp3'},
        'document': {'.pdf'},
        'image': {'.jpg', '.jpeg', '.png'}
    }

    MAX_FILE_SIZE = {
        'video': 5 * 1024 * 1024 * 1024,      # 分片总大小上限 5GB
        'audio': 5 * 1024 * 1024 * 1024,      # 分片总大小上限 5GB
        'document': 5 * 1024 * 1024 * 1024,   # 分片总大小上限 5GB
        'image': 10 * 1024 * 1024             # 10MB，不允许借分片绕过
    }

    async def upload_resource(
        self,
        db: AsyncSession,
        section_id: int,
        file: UploadFile,
        resource_type: ResourceTypeEnum
    ) -> Resource:
        """上传学习资源"""
        # 验证文件格式
        file_ext = Path(file.filename).suffix.lower()
        if file_ext not in self.ALLOWED_EXTENSIONS[resource_type]:
            raise ValueError(f"不支持的文件格式: {file_ext}")

        # 验证文件大小
        content = await file.read()
        file_size = len(content)
        if file_size > self.MAX_FILE_SIZE[resource_type]:
            raise ValueError(f"文件大小超出限制: 最大{self.MAX_FILE_SIZE[resource_type] // (1024*1024)}MB")

        # 生成存储路径
        file_path = f"courses/{section_id}/{uuid.uuid4()}{file_ext}"

        # 上传文件
        file_url = await file_service.upload(content, file_path)

        # 提取元数据
        metadata = await self._extract_metadata(content, resource_type)

        # 创建记录
        resource = Resource(
            section_id=section_id,
            resource_type=resource_type,
            file_name=file.filename,
            file_url=file_url,
            file_size=file_size,
            **metadata
        )
        db.add(resource)
        await db.commit()
        await db.refresh(resource)

        return resource

    async def _extract_metadata(
        self,
        content: bytes,
        resource_type: str
    ) -> dict:
        """提取文件元数据"""
        metadata = {}

        if resource_type == 'video':
            # 使用ffprobe提取视频信息
            duration, resolution = await self._get_video_info(content)
            metadata['duration'] = duration
            metadata['resolution'] = resolution

            # 生成缩略图
            thumbnail_url = await self._generate_thumbnail(content)
            metadata['thumbnail_url'] = thumbnail_url

        elif resource_type == 'audio':
            # 提取音频时长
            duration = await self._get_audio_duration(content)
            metadata['duration'] = duration

        return metadata
```

```python
        raise HTTPException(status_code=404, detail="资源不存在")

    # 删除资源
    await resource_service.delete_resource(db, resource_id)

    return ApiResponse(message="删除成功")
```

```python
# models/resource.py
from sqlalchemy import Column, Integer, String, DateTime, ForeignKey, Text
from sqlalchemy.orm import relationship
from datetime import datetime

class Resource(Base):
    __tablename__ = "resources"

    id = Column(Integer, primary_key=True, index=True)
    section_id = Column(Integer, ForeignKey("sections.id"), nullable=False)
    resource_type = Column(String(20), nullable=False)  # video/audio/document/image
    file_name = Column(String(255), nullable=False)
    file_url = Column(Text, nullable=False)
    file_size = Column(Integer, nullable=False)
    duration = Column(Integer, nullable=True)  # 时长（秒）
    resolution = Column(String(20), nullable=True)  # 分辨率
    thumbnail_url = Column(Text, nullable=True)
    created_at = Column(DateTime, default=datetime.utcnow)

    # 关系
    section = relationship("Section", back_populates="resources")
```
