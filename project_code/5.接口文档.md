## 一、接口规范

### 1.1 请求规范

#### 请求头（Headers）

```http
Content-Type: application/json
Authorization: Bearer {access_token}  # 需要认证的接口
```

#### 请求方法

- `GET`：查询数据
- `POST`：创建数据
- `POST`：更新数据
- `POST`：删除数据

### 1.2 响应规范

#### 成功响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    // 响应数据
  }
}
```

#### 失败响应格式

```json
{
  "code": 400,
  "message": "错误信息描述",
  "data": null
}
```

#### 分页响应格式

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "items": [],
    "total": 100,
    "page": 1,
    "page_size": 20,
    "total_pages": 5
  }
}
```

### 1.3 认证机制

#### JWT令牌

- **访问令牌（Access Token）**：有效期24小时，用于API请求认证
- **刷新令牌（Refresh Token）**：有效期7天（记住我：30天），用于获取新的访问令牌

#### 令牌使用

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 1.4 权限控制

#### 角色定义

- `student`：学员
- `teacher`：讲师
- `admin`：管理员

#### 权限标识

接口文档中使用以下标识表示权限要求：

- 🔓 **公开接口**：无需登录
- 🔒 **需要登录**：所有角色
- 👨‍🎓 **学员权限**：仅学员
- 👨‍🏫 **讲师权限**：仅讲师
- 👨‍💼 **管理员权限**：仅管理员
- 👨‍🏫👨‍💼 **讲师或管理员**：讲师和管理员

### 1.5 文件上传规范

#### 小文件上传（<=500MB）

```http
POST /api/v1/upload/file
Content-Type: multipart/form-data

file: [文件二进制数据]
```

#### 大文件分片上传（>500MB，且总大小 <=5GB）

**步骤1：初始化上传**

```http
POST /api/v1/upload/init
{
  "file_name": "video.mp4",
  "file_size": 5368709120,
  "chunk_size": 10485760,
  "content_type": "video/mp4"
}
```

**步骤2：上传分片**

```http
POST /api/v1/upload/chunk
Content-Type: multipart/form-data

upload_id: "uuid"
chunk_index: 0
chunk: [分片二进制数据]
```

**步骤3：完成上传**

```http
POST /api/v1/upload/complete
{
  "upload_id": "uuid"
}
```

### 1.6 分页参数

所有列表接口支持分页参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 20 | 每页数量 |

### 1.7 错误码规范

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或令牌过期 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如用户名已存在） |
| 422 | 数据验证失败 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |

## 二、用户认证模块

### 2.1 用户注册

**接口路径**：`POST /api/v1/auth/register`
**权限要求**：🔓 公开接口

#### 请求参数

```json
{
  "username": "zhangsan",
  "email": "zhangsan@example.com",
  "phone": "13800138000",
  "password": "Password123",
  "confirm_password": "Password123",
  "role": "student",
  "captcha": "1234",
  "email_code": "123456",
  "referrer_email": "admin@example.com"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名，4-20位字符 |
| email | string | 是 | 邮箱 |
| phone | string | 是 | 手机号，11位 |
| password | string | 是 | 密码，8-20位，包含字母和数字 |
| confirm_password | string | 是 | 确认密码 |
| role | string | 是 | 角色：student/teacher/admin |
| captcha | string | 是 | 图形验证码 |
| email_code | string | 是 | 邮箱验证码 |
| referrer_email | string | 否 | 推荐人邮箱（注册管理员时必填） |

#### 响应示例

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": 1,
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "role": "student",
    "status": "active",
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",
    "expires_in": 86400
  }
}
```

#### 业务规则

- 用户名全局唯一
- 邮箱全局唯一
- 手机号全局唯一
- 讲师注册后状态为`pending`，需要管理员审核
- 管理员注册需要已存在管理员的邮箱推荐
- 学员注册后立即可用，自动登录

### 2.2 用户登录

**接口路径**：`POST /api/v1/auth/login`
**权限要求**：🔓 公开接口

#### 请求参数

```json
{
  "login_id": "zhangsan@example.com",
  "password": "Password123",
  "remember_me": true
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| login_id | string | 是 | 登录账号（邮箱或手机号） |
| password | string | 是 | 密码 |
| remember_me | boolean | 否 | 记住我，默认false |

#### 响应示例

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "user_id": 1,
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "nickname": "张三",
    "avatar_url": "https://example.com/avatar.jpg",
    "role": "student",
    "status": "active",
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",
    "expires_in": 86400
  }
}
```

#### 业务规则

- 支持邮箱或手机号登录
- 密码连续错误5次，账号锁定30分钟
- 勾选"记住我"时，刷新令牌有效期延长至30天
- 登录成功后记录登录时间和IP地址

## 七、反馈消息模块

### 7.1 提交反馈

**接口路径**：`POST /api/v1/feedbacks`
**权限要求**：🔒 需要登录

```json
{

  "images": [
    "https://example.com/screenshot1.jpg",
    "https://example.com/screenshot2.jpg"
  ]
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| feedback_type | string | 是 | 反馈类型：system/course |
| course_id | integer | 否 | 课程ID（课程问题时必填） |
| content | string | 是 | 反馈内容，10-500字符 |

```json

  "message": "反馈提交成功",
  "data": {
    "feedback_id": 1,
    "created_at": "2026-03-17T10:00:00"
  }
}
```

#### 业务规则

- 反馈内容10-500字符
- 截图最多8张，单张限制5MB
- 同一用户24小时内最多提交10条反馈

## 九、错误码说明

### 9.1 通用错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 200 | 成功 | - |
| 400 | 请求参数错误 | 检查请求参数格式和类型 |
| 401 | 未认证或令牌过期 | 重新登录获取令牌 |
| 403 | 权限不足 | 检查用户角色权限 |
| 404 | 资源不存在 | 检查资源ID是否正确 |
| 409 | 资源冲突 | 检查唯一性约束 |
| 422 | 数据验证失败 | 检查数据格式和业务规则 |
| 429 | 请求过于频繁 | 稍后重试 |
| 500 | 服务器内部错误 | 联系管理员 |
