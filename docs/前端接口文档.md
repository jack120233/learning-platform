# 前端接口文档

> 基础路径: `/api/v1` | 认证方式: JWT Bearer Token

---

## 一、认证模块 (auth)

| 接口 | 方法 | 路径 | 请求字段 |
|------|------|------|----------|
| 登录 | POST | `/auth/login` | `login_id`, `password`, `remember_me` |
| 注册 | POST | `/auth/register` | `username`, `email`, `phone`, `password`, `confirm_password`, `role`, `captcha`, `captcha_id`, `email_code`, `referrer_email?` |
| 获取图形验证码 | GET | `/auth/captcha` | - |
| 发送邮箱验证码 | POST | `/auth/send-email-code` | `email`, `purpose` (register/reset_password) |
| 密码重置 | POST | `/auth/reset-password` | `login_id`, `email_code`, `new_password`, `confirm_password` |
| 刷新Token | POST | `/auth/refresh` | `refresh_token` |
| 退出登录 | POST | `/auth/logout` | - |

## 六、讲师端模块 (teacher)

### 课程管理

| 接口 | 方法 | 路径 | 请求字段 |
|------|------|------|----------|
| 我的课程列表 | GET | `/courses/my-courses` | `status?` (all/draft/published/archived), `keyword?`, `page?`, `page_size?` |
| 创建课程 | POST | `/courses` | `title`, `cover_url`, `summary`, `description?`, `category_id`, `tags?` |
| 更新课程 | POST | `/courses/{courseId}` | `title?`, `cover_url?`, `summary?`, `description?`, `category_id?`, `tags?` |
| 发布课程 | POST | `/courses/{courseId}/publish` | - |
| 下架课程 | POST | `/courses/{courseId}/archive` | `archive_reason` |
| 删除课程 | POST | `/courses/{courseId}/delete` | - |

| 删除章节 | POST | `/courses/{courseId}/chapters/{chapterId}/delete` | - |
| 更新章节排序 | POST | `/courses/{courseId}/chapters/sort` | `chapter_ids` (数组) |

| 接口 | 方法 | 路径 | 请求字段 |

| 删除资源 | POST | `/courses/{courseId}/sections/{sectionId}/resources/{resourceId}/delete` | - |

### 文件上传

| 接口 | 方法 | 路径 | 请求字段 |
|------|------|------|----------|
| 普通上传 | POST | `/upload/file` | `file` (FormData) |
| 初始化分片上传 | POST | `/upload/init` | `file_name`, `file_size`, `chunk_size` |
| 上传分片 | POST | `/upload/chunk` | `upload_id`, `chunk_index`, `chunk` (FormData) |
| 完成分片上传 | POST | `/upload/complete` | `upload_id`, `file_name`, `total_chunks` |

## 通用响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

## 分页响应格式

```json
{
  "items": [...],
  "total": 100,
  "page": 1,
  "page_size": 10,
  "total_pages": 10
}
```
