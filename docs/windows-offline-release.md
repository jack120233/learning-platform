# Windows 离线交付说明

## 交付内容

安装包会在当前用户目录下安装一个本地运行的学习平台，并在桌面生成 `学习平台` 快捷方式。

- 双击桌面快捷方式后，程序会在本机静默启动
- 默认浏览器会自动打开 `http://127.0.0.1:8000/login`
- 所有课程数据、资源文件、日志和缓存均保存在本机，不依赖外网

## 使用说明

1. 安装 `学习平台-Setup.exe`
2. 安装完成后可直接勾选“立即启动学习平台”
3. 也可以后续双击桌面上的 `学习平台` 快捷方式
4. 如果需要停止后台服务，可在开始菜单中点击 `停止学习平台`
5. 登录账号由交付方另行提供，请妥善保管

## 运行特性

- 启动器会优先使用 `127.0.0.1:8000`
- 如果 `8000` 被占用，会自动尝试后续端口并打开实际登录地址
- 如果平台已经在运行，会直接打开已有实例的登录页，不会重复启动多个实例

## 构建说明

源码环境下可执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows-release.ps1
```

脚本会完成：

- 构建前端 `UI/dist`
- 使用 PyInstaller 生成后端独立运行时
- 组装 `build/windows-release/bundle/`
- 如果本机已安装 Inno Setup，则继续输出 `学习平台-Setup.exe`

## 卸载策略

卸载时会同时清理安装目录下的：

- `data/`
- `logs/`
- `uploads/`

这套安装包定位为演示/交付版，因此默认执行完整清理。
