## 2. 产品概述

### 2.1 产品定位
本系统为在线视频学习平台，面向学员、讲师、管理员提供课程学习、课程管理、用户管理、反馈与消息通知等能力，重点支持视频、音频、PDF/PPT/Word、图片等多种学习资源的在线消费。

### 2.2 业务核心模块
平台核心业务由以下五部分构成：

1. 用户注册与登录
2. 课程生产与管理（讲师端）
3. 课程浏览与学习（学员端）
4. 后台运营与管理（管理员端）
5. 反馈与消息通知

## 3. 用户角色与权限设计

### 3.1 角色定义

| 角色 | 是否登录 | 主要能力 |
|---|---|---|
| 游客 | 否 | 浏览首页、搜索课程、查看课程列表、进入登录/注册页 |
| 学员 | 是 | 查看课程详情、学习已发布课程、查看学习记录、修改个人资料、提交反馈、查看消息 |
| 待审核讲师 | 是 | 可登录并具备学员能力，但不可创建、编辑、发布课程 |
| 讲师 | 是 | 具备学员能力，并可管理自己的课程和课程内容 |
| 管理员 | 是 | 可管理所有用户、审核讲师、管理公告、反馈、角色权限及全量课程 |

### 3.2 角色权限说明

#### 游客
- 可访问：首页、课程列表、登录页、注册页、找回密码页
- 不可直接进入学习页
- 点击课程学习相关操作时，需引导登录

#### 学员
- 可访问：首页、课程详情、学习页、个人中心、学习记录、消息中心、反馈
- 仅可学习已发布课程
- 不可进入讲师端和管理员后台

#### 待审核讲师
- 注册后自动登录
- 前端需显著提示“讲师审核中”
- 可正常作为学员浏览和学习课程
- 不展示或禁用“创建课程”“编辑课程”“发布课程”等入口

#### 讲师
- 可访问讲师端课程管理模块
- 仅可管理自己创建的课程
- 可查看自己课程的草稿、已发布、已归档/已下架状态内容

#### 管理员
- 可访问管理员后台
- 可管理用户、审核讲师、处理反馈、管理公告、配置角色权限
- 可越权查看和管理所有课程

### 3.3 登录态与路由拦截规则
前端需对以下场景做统一拦截：

- 未登录访问需鉴权页面：跳转登录页
- 学员访问讲师端：提示“无权限访问”
- 非管理员访问后台：提示“无权限访问”
- 待审核讲师进入课程管理页面：提示“讲师审核通过后可使用该功能”
- token 失效时优先自动刷新，刷新失败后跳转登录页

## 5. 核心业务流程概览

### 5.1 学员主链路
1. 用户进入首页浏览课程
2. 通过搜索或列表点击进入课程详情
3. 登录后进入课程学习页
4. 点击具体资源进行学习
5. 系统自动记录学习进度
6. 用户在个人中心查看学习记录、消息和反馈处理结果

### 5.2 注册登录主链路
1. 用户注册账号
2. 系统完成基础信息校验
3. 注册成功后自动登录或进入审核流程
4. 用户后续通过邮箱/手机号登录
5. 登录态失效时自动刷新，失败则重新登录

### 5.3 讲师课程管理主链路
1. 讲师进入课程管理页面
2. 创建课程并填写基础信息
3. 维护课程目录和资源
4. 保存草稿
5. 满足条件后发布课程
6. 后续可编辑、归档/下架或删除课程

### 5.4 管理员运营主链路
1. 管理员登录后台
2. 审核待审核讲师
3. 管理用户状态
4. 管理公告与反馈
5. 配置角色权限

为用户提供课程发现入口，支持浏览、搜索、筛选和进入课程详情。

### 6.1.2 页面模块
- 全局导航栏
- Banner 区
- 搜索框
- 分类筛选区
- 推荐课程 / 课程列表区
- 分页区
- 页脚

### 6.1.3 导航栏
包含以下内容：

- Logo
- 主导航（首页、职业培训课堂、考培活动报名、职业技能竞赛、师资培训、考试考核中心、更多）
- 学院课程快捷入口
- 搜索入口
- 用户头像及下拉菜单

未登录态展示：
- 登录
- 注册

已登录态展示：
- 个人中心
- 我的学习
- 消息中心
- 退出登录

讲师额外展示：
- 课程管理

管理员额外展示：
- 后台管理

### 6.1.4 Banner 区
- 展示平台主推课程、活动、系统升级信息
- 支持轮播或静态焦点图
- 支持点击跳转指定课程或专题页

### 6.1.5 课程列表区
课程卡片需展示：
- 课程封面
- 课程名称
- 讲师名称
- 课程简介摘要（可选）
- 学习人数或发布信息（可选）

交互要求：
- 点击卡片进入课程详情页
- 支持分页，每页默认 20 条
- 默认按发布时间倒序展示已发布课程

### 6.1.6 搜索与筛选
支持：
- 按课程标题、讲师名称模糊搜索
- 支持空格分词
- 支持分类筛选
- 支持排序：最新发布 / 最多学习
- 登录用户自动记录最近 10 条搜索历史
- 支持展示热门搜索词

### 6.1.7 状态要求
- 加载中：骨架屏
- 无课程：显示“暂无课程，敬请期待”
- 搜索无结果：显示“未找到相关课程”
- 加载失败：显示错误提示及重试按钮

## 6.2 注册页

### 6.2.1 页面目标
支持学员、讲师、管理员注册，覆盖校验、验证码、审核状态提示等完整交互。

### 6.2.2 表单字段
公共字段：
- 用户名
- 密码
- 确认密码
- 手机号
- 图形验证码
- 邮箱
- 邮箱验证码
- 角色选择

管理员额外字段：
- 推荐管理员邮箱

### 6.2.3 字段规则
- 用户名：4-20 位，支持字母、数字、下划线
- 密码：8-20 位，必须包含字母和数字
- 确认密码：需与密码一致
- 手机号：11 位中国大陆手机号
- 图形验证码：4 位
- 邮箱验证码：6 位，10 分钟内有效

### 6.2.4 注册流程

#### 学员注册
1. 填写完整信息并选择“学员”
2. 系统校验用户名、手机号、邮箱唯一性
3. 校验密码、图形验证码、邮箱验证码
4. 注册成功后自动登录并跳转首页

#### 讲师注册
1. 填写与学员相同的基础信息并选择“讲师”
2. 注册成功后自动登录
3. 前端展示“讲师审核中”提示
4. 当前账号仅具备学员能力
5. 审核通过后通过站内消息通知用户

#### 管理员注册
1. 填写基础信息并选择“管理员”
2. 额外填写推荐管理员邮箱
3. 提交后等待审核处理

### 6.2.5 异常提示
- 用户名已存在：`该用户名已被使用`
- 手机号已存在：`该手机号已被使用`
- 邮箱已存在：`该邮箱已被使用`
- 密码格式不正确：`密码需为 8-20 位字母 + 数字组合`
- 验证码错误或过期：`验证码错误或已过期，请重新获取`
- 推荐管理员邮箱无效：`推荐管理员账号不存在，请确认后重新输入`
- 网络异常：`网络连接失败，请稍后重试`

## 6.3 登录页

### 6.3.1 页面目标
支持邮箱或手机号登录，并处理记住我、账号锁定、token 刷新等场景。

### 6.3.2 页面模块
- 登录方式切换（邮箱 / 手机号）
- 账号输入框
- 密码输入框
- 记住我
- 登录按钮
- 去注册入口
- 忘记密码入口

### 6.3.3 登录规则
- 用户可选择邮箱或手机号登录
- 密码连续错误 5 次，账号锁定 30 分钟
- 登录成功后获取访问令牌与刷新令牌
- 记住我勾选时刷新令牌有效期 30 天，否则 7 天
- access token 有效期 24 小时

### 6.3.4 登录成功后的页面跳转
- 学员：跳转首页或登录前目标页
- 待审核讲师：跳转首页并展示审核中提示
- 讲师：跳转首页或课程管理页
- 管理员：跳转后台管理页

### 6.3.5 异常提示
- 账号不存在或密码错误：`账号不存在或密码错误`
- 账号锁定：`账号已锁定，请 30 分钟后重试`
- 账号禁用：`账号已被禁用，请联系管理员`

## 6.4 找回密码页

### 6.4.1 页面目标
支持未登录用户通过邮箱或手机号完成密码重置。

### 6.4.2 页面流程
1. 选择找回方式：邮箱 / 手机号
2. 输入账号信息
3. 获取验证码
4. 输入验证码
5. 输入新密码与确认密码
6. 提交成功后跳转登录页

### 6.4.3 业务规则
- 邮箱方式：向绑定邮箱发送验证码
- 手机号方式：前端脱敏展示绑定邮箱，并向绑定邮箱发送验证码
- 验证成功后允许设置新密码

### 6.4.4 异常提示
- 账号未注册：`该邮箱 / 手机号未注册账号`
- 验证码错误或过期：`验证码错误或已过期`
- 新密码格式错误：`密码需为 8-20 位字母 + 数字组合`
- 两次输入不一致：`两次输入的新密码不一致`

### 6.5.1 页面目标
展示课程完整信息，并作为学习入口页。

### 6.5.2 页面模块

包含：

### 6.5.6 权限与状态
- 仅已登录用户可进入课程学习页
- 仅已发布课程可被普通用户查看与学习

### 6.5.7 异常状态
- 课程不存在：`该课程不存在或已下架`
- 未登录：`请先登录，再查看课程详情`
- 网络异常：`课程详情加载失败，请稍后重试`

## 6.6 沉浸式学习页

### 6.6.1 页面目标
为学员提供统一的多媒体学习体验，支持学习进度同步与资源切换。

### 6.6.2 页面布局
- 左侧深色侧边栏
- 右侧主内容区
- 整体建议采用满屏 `100vh` 布局
- 仅侧边栏内容区和文档阅读区内部滚动

### 6.6.3 左侧侧边栏
包含双 Tab：

1. **当前任务**
   - 展示当前任务下的学习子项
   - 悬浮时展示二级资源菜单
   - 展示资源名称、资源图标、学习进度百分比

2. **目录**
   - 展示完整课程树形目录
   - 支持章节 / 小节折叠展开
   - 支持快速跳转

### 6.6.4 右侧主内容区
支持以下内容类型：

- 视频播放器
- 音频播放器
- PDF/PPT/Word 阅读组件
- 图片查看器
- 空状态占位图

### 6.6.5 资源类型与交互

#### 视频学习
- 支持播放、暂停、拖动进度、全屏
- 每 30 秒自动保存一次播放进度
- 播放完成后自动跳转下一资源
- 再次进入时从上次进度恢复

#### 音频学习
- 支持播放、暂停、进度恢复
- 每 30 秒自动保存播放进度
- 播放结束后自动进入下一资源

#### 文档学习
- 支持 PDF/PPT/Word 在线预览
- 支持翻页、页码跳转、全屏、下载
- 打开后可标记该资源为已完成

#### 图片学习
- 支持放大、缩小、旋转、切换、多图查看、全屏预览
- 打开后可标记该资源为已完成

### 6.6.6 关键交互要求
- 左侧资源切换时，右侧内容需平滑切换
- 不同资源类型切换时展示 Loading 或骨架屏
- 目录与主内容需保持当前资源高亮同步
- 学习进度需反馈到左侧资源项百分比

### 6.6.7 状态设计
- 未选择资源：显示“暂无课件”
- 资源加载中：显示骨架或 loading
- 资源不存在：显示“文件不存在”
- 格式不支持：显示“暂不支持该文件格式”
- 网络中断：暂停播放并显示提示
- 课程已下架：提示“该课程已下架或删除，无法继续学习”

### 6.6.8 交互细节
- 当前任务悬浮菜单需增加防抖，避免闪烁
- 视频与文档加载建议懒加载
- 学习进度保存建议静默执行，避免频繁打断用户

## 6.7 个人中心

## 6.7.1 个人基本信息页

### 功能说明
支持查看并修改个人资料。

### 展示字段
- 用户头像（如有）
- 用户名
- 昵称
- 邮箱

## 7. 关键业务规则与前端状态映射

## 7.1 课程状态规则
前端展示与后端状态建议统一映射如下：

| 展示文案 | 内部状态值 | 说明 |
|---|---|---|
| 草稿 | `draft` | 仅讲师本人和管理员可见 |
| 已发布 | `published` | 普通用户可见并可学习 |
| 已下架 | `archived` | 学员不可见，不可继续学习 |

> 说明：前端展示文案可使用“已下架”，内部状态值建议保持 `archived`。

## 7.2 用户状态规则

| 状态 | 前端处理 |
|---|---|
| 正常 | 正常使用全部角色权限 |
| 禁用 | 登录后提示账号不可用 |
| 待审核讲师 | 可登录，可学课程，不可建课 |
| 讲师审核通过 | 解锁课程管理入口 |

## 7.3 学习权限规则
- 普通用户 / 学员：只能学习已发布课程
- 待审核讲师：仅保留学员能力
- 讲师：可查看自己所有课程状态
- 管理员：可查看与管理所有课程

## 7.4 登录态规则
- 前端需保存登录态并控制页面访问
- access token 失效时自动尝试刷新
- 刷新失败则清空本地状态并跳转登录页
- 退出登录后清除 token、用户信息、页面缓存

## 8. 通用交互规范

### 8.1 表单交互
- 输入框支持实时校验

- 删除消息

- 大文件场景需提示断点续传能力

## 9. 异常处理与边界场景

## 9.1 通用异常
- 网络异常
- 接口超时
- 服务异常
- 权限不足
- 资源不存在
- 登录失效

统一要求：
- 提示文案清晰
- 支持重试
- 不出现白屏或无反馈状态

## 9.2 页面状态统一要求
每个核心页面必须覆盖以下状态：

1. 初始化加载中
2. 加载成功
3. 空数据
4. 加载失败
5. 权限不足
6. 数据不存在或已删除

## 9.3 学习页特殊边界
- 未选择资源时显示空状态
- 视频加载失败时可重试
- 网络中断时自动暂停
- 当前课程已下架时禁止继续学习
- 文档资源过大时需提供加载中反馈
- 资源切换过快时避免闪屏或进度错乱

## 10. 非功能需求

## 10.1 性能要求
- 首页、课程详情页 FCP 目标：1.5 秒以内
- 学习页可交互时间 TTI 目标：2.5 秒以内
- 视频需支持流式播放
- PDF/PPT 建议使用懒加载、分页加载或流式下载
- 大列表建议分页或虚拟滚动

## 10.2 兼容性要求
- 兼容 Chrome、Edge、Firefox、Safari 主流版本
- 主适配分辨率：1920 × 1080
- 向下兼容至 1280 宽度
- 预留 Pad 端响应式布局能力
- 窄屏下左侧边栏可折叠为 Drawer

## 10.3 稳定性要求
- 所有接口请求需有超时与失败提示
- 重复点击需做防抖或按钮禁用
- 上传、删除、发布等关键操作需给出结果反馈
- 页面跳转过程中需避免数据闪烁和权限穿透

## 10.4 安全要求
- 前端只负责展示与拦截，不信任本地角色信息
- 最终权限以服务端返回为准
- 敏感页面必须做登录态和角色判断
- 敏感操作必须防止重复提交

## 14. 总结

本前端需求文档围绕“用户注册登录、课程浏览、课程学习、讲师课程管理、管理员后台、反馈与消息”六大方向进行了完整梳理，既保留了现有设计稿中的课程门户、课程详情、沉浸式学习页等核心界面特征，也补齐了实际业务流程中所需的注册登录、个人中心、讲师端、管理端、状态流转和异常处理要求。

前端开发应优先保障以下主链路完整可用：

- 用户注册 / 登录
- 浏览课程 / 查看详情
- 进入学习 / 自动记录进度
- 讲师建课 / 发课
- 管理员审核 / 处理反馈
